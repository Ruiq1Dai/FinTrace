# JRKJ 前端初版

这是一个无需构建工具的工作台原型。页面会通过 `POST /api/analyze` 调用真实后端，并从 `InvestigationRun` 更新结论、置信度、工具调用数和证据数。后端不可用时会明确显示“当前显示演示数据”，不会把静态内容冒充为实时分析结果。

当前尚未动态更新所有图表、证据行和图谱视图；这些区域继续作为演示回退，下一阶段通过同源开发服务器逐步接入。

启动同源开发服务器：

```bash
python main.py --port 8000
```

然后访问 `http://127.0.0.1:8000/`。未配置模型 API Key 时，页面会显示结构化后端错误并保留演示回退。

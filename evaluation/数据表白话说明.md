# JRKJ 五类数据白话说明

标注时不需要学习金融知识。只需把 Agent 回答中的数字或“无法回答”结论，与标注 CSV 的 `参考答案` 和 `参考答案白话来源定位` 两列逐项比较。

## 五类数据的新名称

| 原目录 | 白话名称 | 它直接告诉你什么 |
| --- | --- | --- |
| `data/2/上市公司前十大股东.xlsx`（原始表名：`clean.xlsx`） | 公司前十大股东记录 | 哪些股东持有某家公司、持有多少、占多少比例 |
| `data/3/公司风险公告目录.xlsx`（原始表名：`clean.xlsx`） | 公司风险公告目录 | 某公司发布过哪些风险类公告及公告日期；这里只是目录，没有公告正文 |
| `data/4` | 公司财务情况记录 | 公司赚了多少钱、手里和账上有什么、现金实际进出多少 |
| `data/5/rr_main_202605281537.csv` | 证券机构公司研究报告 | 证券机构对公司的描述、预测和风险提示；预测是观点，不是已经发生的事实 |
| `data/1/用户问题记录.xlsx`（原始表名：`clean.xlsx`） | 用户问题记录 | 用户提出的问题；它不是回答金融问题的证据表，本轮 19 题不会从这里取答案 |

`data/4` 因内容多，实际拆成三个子表：

| 原文件 | 白话名称 | 最简单的理解 |
| --- | --- | --- |
| `ashareincome_202605261519.csv` | 公司收入与利润记录 | 卖了多少钱，最后赚了还是亏了 |
| `asharebalancesheet_202605261517.csv` | 公司资产、欠款与资金余额记录 | 某一天公司有多少钱、货物、待收款和借款 |
| `asharecashflow_202605261518.csv` | 公司现金实际流入流出记录 | 一段时间内真实收到和付出了多少现金 |

## 行号规则

CSV 中的定位统一写成“表格第 N 行”，含义是用 Excel 或 WPS 打开后左侧显示的行号，表头算第 1 行。Excel 文件也采用同一规则，并额外写明工作表名称。

## 最快标注方法

1. 先看 `参考答案`，再看 `参考答案白话来源定位` 中列出的原始行和关键值。
2. 对比 `agent_回答`。核心数字、对象和结论都一致，就把 `是否正确` 填为“是”；否则填“否”。
3. `agent_白话来源定位` 只表示 Agent 实际查过什么。它若写“没有查询”，不要把参考答案的来源算成 Agent 查过的来源。
4. Agent 编造了来源中不存在的具体事实或数字，`是否幻觉` 填“是”；只是明确说数据不足，通常不算幻觉。
5. 不需要自行解释任何财务术语；括号内已给出核对所需的最低限度含义。
